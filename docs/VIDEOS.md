# 视频库

`/videos/` 是博客里的个人视频列表。它不是第三方实时接口，也不做抓取：每条视频都是 `source/_data/videos.yml` 里的一个条目，文件放自己的存储（仓库小文件或 Cloudflare R2）。

## 现在能做什么

- 视频卡片：封面、标题、话题、描述、标签、时长。
- 话题标签页：页面读取 `video-topics.yml` 里的最多 10 个话题，生成“全部话题 / 技术 / 旅行 / …”标签，点哪个就切换哪一类。
- 搜索标题/描述/话题/标签；话题、搜索、收藏可以同时叠加。
- 点卡片打开播放器；支持键盘 Esc 关闭。
- 收藏：点卡片右上角的星；收藏存在浏览器 `localStorage`，单设备有效。
- 导出收藏为 `video-favorites.json`，换浏览器/清缓存前可以备份；支持再导入合并。
- 没有视频时显示空状态，不会伪造示例内容。

## 添加一条视频

在 Pages CMS 的“视频”里新增一条：

| 字段 | 说明 |
|---|---|
| 视频 ID | 稳定英文 ID，例如 `trip-2026`；收藏靠它，发布后不要改 |
| 标题 | 卡片和播放器显示 |
| 话题 | 必须是“视频话题”里的名称，例如 `技术`、`旅行`、`生活`、`动画`；不填会归入“其他” |
| 描述 | 可选，卡片摘要 |
| 上传视频 | 小文件直接上传到 `source/videos/media/`；输出 `/videos/media/...` |
| 外部 / R2 地址 | 大文件建议用 R2，和“上传视频”二选一 |
| 封面图 | 从 `source/images` 选或上传 |
| 标签 | 可选，多个 |
| 日期 / 时长 | 可选；时长只是显示文本，例如 `03:24` |

保存后提交到 `main`，Deploy Blog 会自动构建；视频库读取构建时生成的 `/videos.json`。

## 管理话题（最多 10 个）

Pages CMS 里还有一个“视频话题”入口，编辑 `source/_data/video-topics.yml`：

```yaml
- name: 技术
- name: 旅行
- name: 生活
```

- 最多 10 个；顺序就是页面上的顺序。
- 新增/改名后，视频条目的“话题”字段要写同一个名称。
- 页面会自动生成“全部话题 + 这些话题”的切换标签；想换分类就改这个文件，不用改代码。
- 视频里填了话题表之外的名字时，会归到“其他”（如果话题表里有“其他”），避免出现孤立标签。

## 永久性要说清楚

- **收藏只是记住 ID**。如果视频文件被删除、R2 地址失效，收藏还在，但播放不了。
- **永久保存 = 你拥有文件 + 有权存 + 自己的存储和备份**。大文件放 R2；建议开版本控制或定期备份。
- 仓库里只建议放小视频；GitHub 仓库和 Pages 产物都有体积限制。
- 外部链接（包括第三方平台）随时可能失效或变私密，不能当永久收藏。
- 只使用自己拍摄或获得授权的内容；不要用这个页面去抓取、转存别人的视频。

## 升级版长什么样

如果以后想要“换手机收藏还在”：

1. 视频文件继续放 R2。
2. 视频元数据和收藏放 Cloudflare D1（或 Supabase）。
3. 用 GitHub 登录，收藏按账号存。
4. R2 开版本控制/备份；视频用固定 ID；可以再加播放列表、合集、分享链接和 HLS。

升级只影响“收藏存在哪、怎么登录”，页面上的卡片、播放器和搜索不需要重做。
