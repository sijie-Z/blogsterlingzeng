四 GB。这是我手头唯一的显卡显存。一张 RTX 3050。

大模型的显存要求是几十 GB 起步的,所以理论上,这条路走不通。

实验记录显示,它走通了。494M 参数的模型,只训练了其中的 0.42%,2M 个参数,推理时跑在这张 3050 上。

<!-- more -->

## 为什么做这件事

调 API 很简单,训练模型很难。难的从来不是跑通一个训练脚本,而是搞明白每一步在干什么。

所以这个项目定的原则很奇怪:不用大显存,不用大模型,不用复杂的工程框架。V0.1 只有四个文件,目标是先看到 loss 下降,再谈其他。

四个阶段,一路从"用预训练模型做分类"走到"微调出自己的问答助手"。

## 阶段一:BERT 新闻分类,验证集 100%

第一阶段是 BERT 做中文新闻四分类:体育、科技、财经、娱乐。400 条数据,标准流程:加载预训练模型、拼接输入、训练、评估。

验证集准确率 100%。这个数字好看得可疑,但它就是这么打印出来的。

然后我单独做了一个测试集——不是从 400 条里随机切的,是另找的数据。准确率 90%。

10% 的差距,这就是过拟合的全部含义。随机切分做验证集,数据特征和训练集高度重合,模型记住答案就能拿高分;独立测试集才测泛化。

这是这个框架里的第一条教训,用一次 100% 换来的:**验证集上的满分不说明模型好,独立测试集才说明。**

## 阶段二:文本匹配,一次诚实的失败

第二阶段是文本匹配:给两句话,判断它们是不是同一个意思。这是短文本语义理解的入门任务。

我用了 225 对自生成的数据,模仿 LCQMC 的格式。结果模型学会了一个最省力的策略:全部预测"不匹配"。Accuracy 44%,F1 30%。

44% 意味着模型什么都没学。为什么分类任务 400 条够用,匹配任务 225 对就不够?

因为任务难度不同。分类是"一个标签概括整段话",匹配是"两个句子的关系判断",后者需要模型见过的关系样本量级完全不同。匹配任务的经验数据是 2000 对起步,我给了十分之一。

这个实验失败了,但我没有删掉它的记录。实验目录里留着完整的脚本、结果和分析,和成功的实验并列。失败记录的价值在于:**它标出了这条路的成本,后来的人不用再付一遍。**

## 阶段三:LoRA 微调 Qwen2.5-0.5B

第三阶段开始训大模型了。Qwen2.5-0.5B,494M 参数。按常规全参微调,光优化器状态就要吃掉几个 GB 的显存,4GB 的卡直接爆。

LoRA 的玩法是把"训练全部参数"换成"训练两个低秩矩阵"。494M 参数只训练 2M 个——0.42%。训练完的 adapter 只有 17MB,4bit 量化之后训练显存只要 2–3GB。

两个细节值得记录。

第一个:微调前后,同一个问题的回答对比。"苏州科技大学在哪"——微调前,模型一本正经地回答"苏州科技大学是 211 工程重点建设高校"。

假的。苏州科技大学不是 211。

微调后,它回答的是知识库里的真实信息。这个对比被我原样贴进了实验记录,一句解释都没加。

第二个:模型学会了自我介绍。微调语料里有问答助手的身份设定,训练完,它回答"你是谁"时会说:"我是实验004a训练出来的问答助手。"

它记住了自己的训练编号。这个细节比任何指标都更能说明"参数被改写了"这件事。

## 阶段四:GeoAI Assistant

最后一个阶段是把前面所有东西拼成一个产品:地理信息问答助手。

架构很简单:

```
用户提问
   │
   ▼
Query Router(关键词规则,决定走哪条路)
   ├──→ LoRA 微调模型(知识问答)
   └──→ TF-IDF 检索 + 大模型生成(RAG)
   │
   ▼
回答
```

Query Router 是一段关键词判断逻辑,不用模型;LoRA 模型回答知识问题;TF-IDF 检索兜底,防止模型编造。后端用 FastAPI 包一层,前端接上就能用。

跑起来的总显存占用:1.4GB。4GB 的 3050 还剩大半。

关于 LoRA 有一个反直觉的结论值得单独说:**训练参数减少了 99.6%,推理速度没有变快。**

原因是 adapter 推理时要合并回原始权重,计算量并没有减少;省的是显存和训练时间,不是推理速度。很多人以为 LoRA 是"让模型跑得快",其实它是"让小显存卡也能训得动"。

## 四个阶段的账本

| 阶段 | 任务 | 结果 | 留下什么 |
|------|------|------|----------|
| BERT 分类 | 新闻四分类 | 验证集 100%,测试集 90% | 过拟合的直观样本 |
| 文本匹配 | 句对关系判断 | Accuracy 44%,F1 30% | 一次诚实的失败记录 |
| LoRA 微调 | Qwen2.5-0.5B | 2M 参数,17MB adapter | 幻觉修复前后对比 |
| GeoAI 产品化 | 问答助手 | 1.4GB 显存可跑 | 一个能用的产品 |

## 给同样条件的人

如果你的显卡也是 4GB,或者还在犹豫"我这配置能不能玩大模型",这个仓库就是答案之一:

- 先做分类,验证集 100% 时记得做独立测试集
- 文本匹配的数据量要求比分类高一个数量级,别用十分之一去试
- LoRA 是 4GB 显卡的唯一出路,adapter 17MB,拷走就用
- 别等"准备好了"再开始,V0.1 只有四个文件,先看到 loss 下降

四 GB 显存,0.42% 的参数,17MB 的 adapter,和一个会自己报出训练编号的问答助手。
